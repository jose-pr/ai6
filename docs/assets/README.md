# Brand assets

The images here are AI6 project brand assets. They are raster-generated artwork, not
traced or vector sources; the icons include their own dark rounded-square backgrounds and
have no transparency.

| File | Size | Use |
| --- | --- | --- |
| `ai6-header.png` | 1294 × 278 | Banner at the top of the repository README |
| `moneypenny-header.png` | 1294 × 278 | Banner at the top of the Moneypenny app README |
| `ai6-128.png` | 128 × 128 | AI6 icon, the documentation site's logo |
| `favicon.png` | 64 × 64 | AI6 icon, the documentation site's favicon |

The Moneypenny app's icons are made from the Moneypenny icon:
`clients/moneypenny/assets/brand/moneypenny-128.png` (128 × 128, her chat avatar),
`clients/moneypenny/web/favicon.png` (64 × 64), `clients/moneypenny/web/icons/`
(192 and 512, plus maskable versions with the art at 80% on its edge colour) and
`clients/moneypenny/windows/runner/resources/app_icon.ico` (16 to 256).
