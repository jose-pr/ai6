# ai6-process-tree

The process-tree kill that the [AI6](https://github.com/jose-pr/ai6) `pipe` and `pty` terminal
providers and the Codex sandbox probe share: a process group and the processes found by parent
from it on Unix, a Job Object on Windows. See the
[API header](https://github.com/jose-pr/ai6/blob/main/crates/process-tree/AGENTS.md).
